02Storage cost by class

Ongoing cost to keep the full dataset in each class for the chosen term. Totals include the one-time upload request cost and any minimum-duration charge. Uploading into S3 is free. The last two cost columns show what it costs to download the share of data set in "% of data retrieved" (100% = the entire dataset): egress alone, and egress plus the cheapest way to get the data out of that class.

  • Intelligent-Tiering rows assume the data is untouched after upload, so objects step down automatically (30 days to Infrequent, 90 days to Archive Instant). The "archive tiers on" row assumes the bucket opts into Archive Access at 90 days and Deep Archive Access at 180 days.
  • Glacier Flexible Retrieval and Deep Archive add about 40 KB of metadata per object (32 KB billed at the class rate, 8 KB at Standard).
  • Egress columns use the internet transfer rates and the "egress spread over" and free-allowance settings in the left panel. "Retrieve + egress all" adds retrieval fees, request fees and any restored-copy cost for the share of data set in "% of data retrieved", using the lowest-cost retrieval option for that class. Untick "Include egress in complete cost" to leave egress out, for example when the data will be used inside AWS. Restore and retrieval costs are always included while egress is on, because data has to be restored or retrieved before it can be downloaded. With egress off, untick "Include restore / retrieval" to see storage alone.
  • PHI / HIPAA controls add a KMS key ($1/month for the billed term), KMS and CloudTrail charges on every upload and read, and, if chosen, a second copy in another region stored in Glacier Deep Archive (copy fee plus storage, 180-day minimum). Log storage is not included and is usually a few dollars a month.
  • One Zone-IA keeps a single copy in one Availability Zone. It is a poor fit for a client's only copy of irreplaceable sequence data.

03Getting data back out of storage

  • "Restore wait" is how long before the data is readable in S3. "Ready to use" adds the download time at the chosen link speed.
  • Restore times are AWS targets. AWS restores large datasets at about 1–2 PB per day per account, so the page uses 1 PB/day as a floor for big restores and marks those rows "(dataset size)". Large restores should be submitted with S3 Batch Operations.
  • Expedited retrieval is meant for urgent requests of up to a few hundred files and is not guaranteed during busy periods unless provisioned capacity is purchased.
  • Restored Glacier data is a temporary copy billed at the Standard rate for the days you keep it. Restored Intelligent-Tiering data moves back to the Frequent Access tier for at least 30 days, shown as one month at the Standard rate. Early deletion before a class minimum is billed as if stored for the full minimum.

04Egress fees

If the client takes out part of the data

Ways to lower egress. Qualified research and academic institutions can use the AWS Global Data Egress Waiver, which waives internet egress up to 15% of the account's total monthly AWS bill when the account is set up through an eligible agreement. AWS also waives internet egress for customers moving all of their data off AWS, on request to AWS Support. Moving data to compute in the same region is free.
Pricing assumptions (edit to update rates)

All values are USD. Storage rates are per GB-month, retrieval per GB, requests per 1,000. Check the AWS S3 pricing page before sending a formal quote.
